# BudgetCartAI - Success Metrics (Acquisition-Grade)

## Activation (Week 1)
- Budget set
- First shopping list or cart created
- At least 5 pantry items added (manual or scan)
- First savings insight viewed

## Engagement (Weekly)
- WAU/MAU
- Weekly loop completion rate (Plan -> Shop -> Update Pantry -> Savings)
- Pantry update frequency per week

## Value Delivered
- Median weekly projected savings
- Median weekly realized savings
- Waste reduction proxy: expired items avoided / alerts acted on

## Retention
- Week 4 retention
- 90-day retention
- Repeated store usage (same store vs multi-store optimization)

## Monetization
- Free->Pro conversion
- Pro retention (month 2+)
- Feature usage within Pro (substitution engine, multi-store optimization, alerts)
